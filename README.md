# Cynbit Solution Finder

A guided service-discovery experience designed to help businesses identify a suitable starting point for their technology needs.

## Problem

Businesses may know the challenge they want to solve but need help identifying which technology service to explore first.

## Solution

Cynbit Solution Finder guides visitors through a short questionnaire and suggests a service direction with practical next steps and a project brief.

## Features

- Goal-based service discovery
- Challenge-specific questions
- Business-stage and investment-preference inputs
- Tailored recommendations and next steps
- Copyable project brief
- Responsive interface

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` with the Live Server extension.

## Limitations

This is a front-end experience. It does not currently store leads, submit data to Cynbit, or use a live AI model. Recommendations are based on predefined rules.
